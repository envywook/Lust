# Lust v0.1.10-alpha

## Постоянная подпись APK

- release APK теперь подписываются постоянным сертификатом Lust, а не временным debug-ключом GitHub runner;
- следующие версии можно устанавливать поверх этой сборки без удаления приложения и потери настроек;
- все ABI-варианты одного релиза используют одинаковый сертификат;
- signing key хранится вне репозитория и восстанавливается в CI только из GitHub Actions Secrets.

## Важно

- при переходе с `v0.1.9-alpha` или более ранней debug-сборки потребуется один раз удалить старое приложение и установить эту версию;
- начиная с `v0.1.10-alpha`, последующие обновления устанавливаются обычным способом поверх текущей версии.

> Alpha-сборка использует постоянную release-подпись Lust.

# Lust v0.1.6-alpha

## Новые протоколы sing-box

- Hysteria2 и alias `hy2://` с TLS, SNI, ALPN, bandwidth и Salamander obfuscation;
- TUIC с UUID/password, congestion control, UDP relay mode и TLS;
- NaiveProxy через `naive+https://` на Cronet-enabled core;
- VLESS/XHTTP, включая TLS/Reality, uTLS fingerprint, host, path, mode и `xPaddingBytes` из `extra`.

## Ядро

- sing-box заменён на воспроизводимый Android API 26 build `1.13.14-extended-2.5.2-lust.1`;
- exact source: `shtorm-7/sing-box-extended@ff11f007ec798136a5de258f947a4f34011a37ea`;
- все четыре ABI закреплены SHA-256 и распространяются отдельным versioned core prerelease;
- Xray отклоняет sing-box-only профили с понятным сообщением вместо запуска несовместимого JSON.

## Проверка

- 75 unit-тестов;
- Android lint и сборка всех ABI + universal APK;
- `sing-box check` на Android API 34 для Hysteria2, TUIC, Naive и VLESS/XHTTP;
- два connect/disconnect цикла, TCP и DNS smoke отдельно для sing-box и Xray, без fatal logs.

> Alpha-сборка использует debug-подпись и предназначена для тестирования.

# Lust v0.1.4-alpha

## Что добавлено

- единая главная с подключением, списком серверов и подписками;
- поиск, группы, избранное и сортировка серверов по имени или TCP endpoint latency;
- безопасный deep-link и clipboard импорт подписок с подтверждением;
- отображение трафика, лимита и срока подписки из `subscription-userinfo`;
- versioned backup через системный Android document picker;
- три понятных режима маршрутизации для Xray и sing-box: всё через VPN, обход LAN и собственные исключения доменов/IP;
- universal APK и отдельные APK для `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`;
- SHA-256 checksums для всех APK.

## Что изменено

- нижняя навигация сокращена до «Главная», «Журнал», «Настройки»;
- основной экран настроек упрощён до выбора маршрутизации; технические параметры доступны по кнопке «Расширенные настройки»;
- URL подписки больше не отображается на главной, чтобы не раскрывать access token;
- ABI-specific APK примерно на 65–68% меньше universal debug APK;
- обновлены README, changelog и правила публикации релизов.

## Безопасность

- внешняя ссылка не запускает автоматическую загрузку подписки;
- backup полностью валидируется перед заменой состояния и требует подтверждения;
- содержимое clipboard, backup и subscription URL не записывается в журнал.

## Проверка

Релиз публикуется только после unit/build/lint, Android API 34 smoke для Xray и sing-box, проверки disconnect/reconnect и отсутствия fatal logs.

> Alpha-сборка использует debug-подпись и предназначена для тестирования.
