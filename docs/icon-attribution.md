# Icon attribution

Navigation and network-check vectors in `app/src/main/res/drawable/` were generated from Iconify icon data without modifying their path geometry.

| Android resources | Iconify IDs | Upstream | License |
|---|---|---|---|
| `ic_settings_filled.xml`, `ic_settings_regular.xml` | `fluent:settings-48-filled`, `fluent:settings-48-regular` | [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) | [MIT](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE) |
| `ic_home_filled.xml`, `ic_home_regular.xml`, `ic_speed_filled.xml`, `ic_speed_regular.xml`, `ic_network_check.xml` | `material-symbols:home-rounded`, `material-symbols:home-outline-rounded`, `material-symbols:speed-rounded`, `material-symbols:speed-outline-rounded`, `material-symbols:network-check-rounded` | [Google Material Symbols](https://github.com/google/material-design-icons) | [Apache-2.0](https://github.com/google/material-design-icons/blob/master/LICENSE) |

Icon metadata and paths were obtained from the official [`iconify/icon-sets`](https://github.com/iconify/icon-sets) collections.
