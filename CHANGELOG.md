# История изменений Lust

Все заметные изменения Android-клиента фиксируются здесь и дублируются в описании соответствующего GitHub Release.

## [Unreleased]

## [0.1.18-alpha] — 2026-07-28

- добавлено прямое перелистывание карусели пальцем с порогом дистанции и поддержкой fling;
- прежняя замена всего блока заменена непрерывным движением за пальцем и плавным доведением после отпускания;
- пустая карточка стала большой кнопкой `+ Добавить подписку`, сразу открывающей экран подписок;
- удалены формулировка «в настройках» и обрезанная mint-полоска под пустой карточкой;
- добавлены unit-тесты жеста и Android-тест навигации пустого состояния.

## [0.1.17-alpha] — 2026-07-28

- исправлено определение флагов по RU/EN имени сервера без зависимости от адреса;
- добавлены шкалы спидометра 1 и 10 Mbps и точное отображение низкой скорости;
- карусель серверов получила заметное направленное перелистывание и последовательную смену подписи;
- текстовая кнопка добавления подписки заменена компактной доступной кнопкой `+`;
- instrumentation-тесты изолированы от ранее импортированных пользовательских данных.

## [0.1.16-alpha] — 2026-07-28

- исправлено открытие Telegram-канала на Android 11+;
- добавлены направленные переходы экранов и скользящая active capsule нижней навигации;
- добавлен вход в управление подписками с пустой главной;
- удалён legacy dashboard подписок, возврат сохраняет исходную вкладку;
- добавлены API 34 regression-тесты Telegram и обоих маршрутов управления подписками.

## [0.1.15-alpha] — 2026-07-27

- Добавлен versioned deep-link формат `mieru://` для быстрого импорта Mieru-профилей с подтверждением и строгой валидацией.

### Добавлено
- полностью обновлённые главная, экран скорости и настройки в едином тёмном MaxSpeedVPN-дизайне;
- расширяемая RU/EN локализация и стабильная общая шапка с Telegram-каналом;
- настоящий последовательный тест скорости download → upload с динамической шкалой 100/500/1000 Mbps;
- массовая проверка задержки серверов (до 10 одновременно, timeout 3 секунды) и одиночный ping через long press;
- popup сервера с просмотром полного конфига и системным Share;
- точные Iconify-иконки навигации с отдельными filled/regular состояниями.

### Изменено
- выбранный сервер в карусели выделяется размером, приглушением соседей и мягкой подсветкой без ободка;
- подпись карусели показывает имя сервера и имя его подписки в одной строке;
- навигация, стрелка спидометра, состояния подключения, загрузка ping и выбор сервера получили короткие плавные анимации и haptic feedback;
- настройки используют ту же фиксированную шапку, что главная и скорость; лишний заголовок удалён.

### Проверено
- API 34 RU/EN: три основные вкладки, fixed header, карусель, mass ping, long-press popup, config Share и download → upload;
- focused unit tests шкалы спидометра и ограниченного параллелизма/одиночного ping;
- ABI-specific и universal release pipeline с постоянной подписью и SHA-256.

## [0.1.4-alpha] — 2026-07-24

### Добавлено
- объединённая главная: подключение, серверы и подписки на одном экране;
- поиск, группы, избранное и сортировка серверов по имени/задержке;
- безопасный импорт подписки через `lust://add` и `lust://subscription` с подтверждением;
- чтение трафика, лимита и срока подписки из стандартного `subscription-userinfo`;
- versioned backup подписок, серверов, выбора, избранного, маршрутизации и VPN-настроек через Android document picker;
- простая маршрутизация: весь трафик через VPN, обход локальной сети или собственные исключения доменов/IP;
- отдельные APK для `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86` и universal APK.

### Изменено
- нижняя навигация сокращена до «Главная», «Журнал», «Настройки»;
- настройки показывают только режим маршрутизации, а ядро, MTU, DNS, IPv6 и backup скрыты в раскрываемом блоке;
- URL подписки больше не показывается на главной, чтобы не раскрывать token;
- ABI-specific APK уменьшают загрузку примерно на 65–68% относительно universal debug APK;
- release workflow требует явные release notes и публикует SHA-256 для всех APK.

### Безопасность
- deep link и clipboard требуют подтверждения до сетевого запроса;
- backup ограничен по размеру, семантически валидируется до записи и восстанавливается транзакционно;
- URL подписок, clipboard и содержимое backup не записываются в журнал.

### Проверено
- clean unit/build/lint и отсутствие ошибок `git diff --check`;
- Android API 34: реальный импорт backup через DocumentsUI;
- Xray и sing-box: по два цикла TCP/DNS, connect/disconnect, очистка TUN и отсутствие fatal logs.

## [0.1.3-alpha] — 2026-07-24

### Добавлено
- настоящий sing-box 1.13.14 runtime с переключением Xray/sing-box;
- lifecycle/crash recovery и fail-closed конвертация конфигурации;
- переработанный Compose-интерфейс;
- лицензия и provenance встроенного sing-box.

### Проверено
- unit/build/lint gates;
- Android API 34: sing-box TCP/DNS, Xray regression, disconnect/reconnect и аварийный cleanup.
